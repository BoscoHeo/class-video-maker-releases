# 학급 영상 제작 프로그램

사진과 동영상을 골라 자막·배경음악·음성을 더하고 학급 추억 영상을 만드는 Windows 프로그램입니다.

## 배포 현황

1.6 정식 배포를 준비하고 있습니다. 실행 파일은 검증 후 이 저장소의 Releases에 게시됩니다.

[배포 파일과 버전 기록](https://github.com/BoscoHeo/class-video-maker-releases/releases)

현재 공개된 실행 파일은 없습니다. 자동 업데이트용 서명키 연결, 실제 갤럭시 APV 영상 및 Windows 업데이트·복구 검증이 남아 있습니다.

## 사용 방법

1. Releases에서 사용할 버전의 Windows 64비트 포터블 ZIP을 받습니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다.
3. 폴더 안의 학급 영상 제작 프로그램.exe를 실행합니다.
4. 함께 제공되는 교사용 PDF 설명서를 확인합니다.

프로그램은 Windows에서 실행됩니다. ZIP에 포함된 파일을 함께 보관하세요.

## 기능

- 사진·동영상 선택과 행사별 사진 배분
- 자막, 배경음악, 음성 트랙을 넣은 MP4 제작
- 사진 사이 크로스디졸브 전환
- APV 영상 호환 변환 기능

실제 갤럭시 APV 촬영 파일의 호환성은 검증 중입니다.

## 업데이트

새 버전과 변경 내용은 Releases에 안내합니다. 서명 기반 자동 업데이트는 연결 및 교체·복구 검증을 마친 뒤 활성화할 예정입니다.
